### Executive Profile

Senior software engineer and systems architect specializing in high-throughput distributed automation, immersive 3D graphics on the open web, and low-latency network telemetry.

* **3D Graphics & Native Web**: Architect of the WARDONE 3D Web Platform utilizing Three.js WebGL2, Google Draco geometry compression, physical gyroscope hardware sensor filtering, and a 120 FPS adaptive mobile touch compositor.
* **Autonomous Distributed Engines**: Architect of enterprise-grade Discord bot infrastructures with real-time stream monitoring across TikTok, Twitch, and YouTube, managed on cloud VPS nodes with PM2 auto-healing.
* **Network & Kernel Telemetry**: Researcher behind Aetherpulse, optimizing multipath dual-radio network handoffs and TCP/IP latency reduction algorithms for competitive gaming and cloud relays.
* **Industrial & Enterprise Systems**: Engineering digital governance, ISO 9001:2015 quality control automation, and enterprise resource pipelines for PT Kediri Chemical Abadi.
